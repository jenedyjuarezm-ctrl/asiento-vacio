# El Asiento Vacío 🇺🇳
Simulador interactivo del Consejo de Seguridad de la ONU.

Ocupas un asiento del Consejo, votas resoluciones reales sin saber el voto oficial y descubres tu coincidencia con tu país y con la mayoría global.

## 🚀 Cómo jugar
Puedes jugar directamente en la web aquí: [https://tu-usuario.github.io/el-asiento-vacio/](https://tu-usuario.github.io/el-asiento-vacio/)
*(Reemplaza "tu-usuario" con tu nombre de usuario de GitHub)*

## 🛠️ Tecnologías
* HTML5
* CSS3 (Diseño responsivo y modo oscuro)
* JavaScript Vanilla (Sin dependencias)

## 📊 Datos
Los resultados de las votaciones están basados en registros oficiales de la ONU (UN Digital Library y UN Press).
